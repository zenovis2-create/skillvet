# Security policy

## Reporting a vulnerability

Please report vulnerabilities through GitHub's private vulnerability reporting flow instead of opening a public issue:

<https://github.com/zenovis2-create/skillvet/security/advisories/new>

Include the affected version, a minimal reproduction, expected impact, and any suggested mitigation. Do not include real credentials or private repository contents.

## Supported versions

Security fixes are provided for the latest published release. Upgrade before reporting an issue that has already been fixed on the default branch.

## Scope

High-impact reports include scanner bypasses that can produce a clean verdict for malicious input, archive extraction outside the temporary target, denial of service from crafted remote inputs, and execution of scanned content. False positives and new heuristic ideas are welcome as regular issues.
